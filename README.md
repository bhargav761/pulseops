# 🚀 PulseOps

### AI-Powered Cloud-Native AIOps Platform for Intelligent Incident Detection, Observability, and DevOps Automation

PulseOps is an enterprise-grade cloud-native AIOps platform that combines Artificial Intelligence, Kubernetes, GitOps, and modern observability tools to simplify production operations.

The platform continuously monitors infrastructure and applications, collects metrics from Prometheus, aggregates logs with Loki, analyzes incidents using Google Gemini AI, stores incident history in SQLite, visualizes system health with Grafana, and automates cloud-native deployment workflows using Docker, Helm, and ArgoCD.

Designed as a production-ready DevOps portfolio project, PulseOps demonstrates real-world implementation of AIOps, observability, Kubernetes operations, infrastructure automation, CI/CD, and cloud-native monitoring.

- 🤖 AI-powered incident analysis using Google Gemini
